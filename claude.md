# CLAUDE.MD

The focus of this project is to scrape data from websites and provide in a normalized format for IT Professionals. Output should always be provided as JSON. 

Scripts that scrape for data should be written for PowerShell v7.5.5 or greater (but never a later major version) and work on both Windows and Linux.

It should be written using portable modules so that they can be run by people outside of this project. Code should be well documented, easy to understand, and not obfuscated. When code from other projects is used, the original project(s) must be cited.

Do not automatically stage new code in the git repository.
